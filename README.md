# Swiss Legal RAG

> Ask a question about Swiss federal law in **German, French, or Italian** — get an answer cited article-by-article, with links to the official [Fedlex](https://www.fedlex.admin.ch) text. Everything runs **locally**: no API keys, no cloud, no data leaving your machine.

> ⚠️ **Not legal advice.** This is a research/portfolio project. Answers are generated by a local LLM and may be wrong or outdated — always verify against the cited official source.

## Why

Swiss federal law is published in three official languages, and the binding version is often not the one you speak. This project demonstrates **cross-lingual retrieval**: ask in French, retrieve the governing German article, get the answer back in French — every claim cited as `[SR 220 Art. 335c]` and linked to the official ELI page.

## Architecture

```
apps/
├── web/          Next.js chat UI — citations as chips linking to Fedlex
├── retrieval/    FastAPI — hybrid search (pgvector + Postgres FTS, RRF) → cross-encoder rerank → RAG with SSE
└── ingestion/    Python CLI — Fedlex SPARQL → Akoma Ntoso XML → 1 article = 1 chunk → embed → index
db/init/          pgvector bootstrap SQL
corpus.yaml       The corpus manifest: ~10 federal acts × 3 languages
```

- **Data:** official Fedlex open data (SPARQL + consolidated-law XML) — no scraping, reuse expressly authorized.
- **Models:** BGE-M3 embeddings + Qwen generation via [Ollama](https://ollama.com), BGE reranker on CPU.
- **Storage:** Postgres 16 + pgvector (Docker), hybrid dense + full-text search fused with RRF.
- **Evaluation:** gold Q&A dataset per language, retrieval/citation/refusal metrics — the scorecard gates every change.

## Quick start

Prerequisites: Docker, [Ollama](https://ollama.com), Python 3.12+, Node 20+.

```bash
cp .env.example .env      # adjust if needed — no secrets required
docker compose up -d      # Postgres + pgvector
```

Ingestion, API, and UI instructions land in each `apps/*/README.md` as milestones complete.
