# desktop

Tauri 2 + Vite + React + Tailwind + HeroUI chat UI (spec §6): SSE streaming, citation chips opening Fedlex ELI pages in the system browser, language switcher, retrieved-articles panel. Talks only to the `retrieval` API (`http://localhost:8000`), never to Postgres.

Prerequisites: Rust toolchain + Tauri system deps (WebView2 ships with Windows 11; `webkit2gtk` on Linux).

Not implemented yet — Milestone 5.
